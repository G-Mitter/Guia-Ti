> **Portal Interno de Autoatendimento, Base de Conhecimento e Notificação de Incidentes em Tempo Real.**

O **Guia-TI** é um portal web desenvolvido para centralizar manuais, boas práticas e procedimentos operacionais de TI para equipes de loja e filiais. A aplicação inclui um sistema dinâmico de alertas de status que notifica usuários em tempo real sobre quedas ou manutenções de servidores, **reduzindo drasticamente a abertura de chamados duplicados no suporte de TI**.

---

## 🎯 Problema vs. Solução

* **O Problema:** Quando um sistema corporativo apresentava instabilidade ou um operador tinha uma dúvida operacional simples, a equipe de suporte recebia dezenas de chamados idênticos de várias lojas ao mesmo tempo, gerando gargalos e atrasando o atendimento de problemas graves.
* **A Solução:** O **Guia-TI** atua como uma camada de **Autoatendimento (Ticket Deflection)**. Ao acessar o portal, o colaborador visualiza imediatamente o status atual do sistema e encontra guias visuais passo a passo para resolução autônoma dos problemas mais frequentes.

---

## ✨ Funcionalidades Principais

* 📖 **Base de Conhecimento (Knowledge Base):** Manuais práticos e objetivos cobrindo falhas comuns em PDVs, impressoras fiscais, leitores de código de barras e conectividade de rede.
* 🚨 **Painel Dinâmico de Alertas de Servidor:** Lógica em **JavaScript** para alteração do status da interface em tempo real, informando instabilidades gerais assim que o usuário acessa o portal.
* 📱 **Interface Intuitiva e Responsiva:** Layout moderno e limpo com **HTML5 e CSS3**, otimizado para navegação rápida por usuários não técnicos em ambiente de loja.
* ⚡ **Performance e Baixo Custo:** Desenvolvido em JavaScript puro (Vanilla JS), sem dependência de bibliotecas externas, garantindo carregamento instantâneo e hospedagem gratuita via GitHub Pages.
